# 怎么安装

要装两个东西，按顺序来。

1. 先装 **Codex App Manager**。这是公司发的管理器，从下载页下载。
2. 再打开管理器，点「安装 Codex」。这一步才是装真正的 Codex。

下载页：[https://github.com/xuzhixiangya/app-manager/releases/tag/company-v0.5.10](https://github.com/xuzhixiangya/app-manager/releases/tag/company-v0.5.10)

Mac、Windows 和 Ubuntu 的安装包都在这个页面上。

## 第一步：看自己的电脑，下载管理器

### Mac

1. 点屏幕左上角的苹果图标，再点「关于本机」。
2. 看「芯片」那一行。


| 芯片                    | 下载这个                                                                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Apple M1、M2、M3、M4     | [CodexAppManager_aarch64.dmg](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_aarch64.dmg) |
| Intel                 | [CodexAppManager_x86_64.dmg](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_x86_64.dmg)   |


近五年买的 Mac 几乎都是 Apple 芯片，下第一个。

下载后：

1. 打开 dmg，把 **Codex App Manager** 拖进「应用程序」。
2. 打开「终端」，整行粘贴后回车：

```bash
xattr -cr "/Applications/Codex App Manager.app"
```

3. 从「应用程序」里打开它。不要从安装盘里打开。
4. 如果仍提示「已损坏」，再执行一次上面的命令，然后重新打开。

### Windows

1. 点开始菜单，打开「设置」，再点「系统」，再点「关于」。
2. 看「系统类型」。


| 系统类型                 | 下载这个                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 64 位操作系统，基于 x64 的处理器 | [CodexAppManager_x64-setup.exe](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_x64-setup.exe)     |
| 基于 ARM 的处理器          | [CodexAppManager_arm64-setup.exe](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_arm64-setup.exe) |


公司里的 Windows 电脑绝大多数是 x64，下第一个。看不清时，也下第一个。

下载后：

1. 双击这个 exe。
2. 如果出现蓝色窗口「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
3. 按向导下一步。装完后从开始菜单打开 Codex App Manager。

### Ubuntu

只支持 Ubuntu 24.04 和 26.04。

1. 打开「终端」，输入 `uname -m`，回车。
2. 看到 `x86_64`，下载 [CodexAppManager_amd64.deb](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_amd64.deb)。看到 `aarch64`，下载 [CodexAppManager_arm64.deb](https://github.com/xuzhixiangya/app-manager/releases/download/company-v0.5.10/CodexAppManager_arm64.deb)。
3. 终端里进入下载文件夹，安装。普通电脑用第一行，ARM 电脑用第二行：

```bash
cd ~/Downloads
sudo apt install ./CodexAppManager_amd64.deb
```

```bash
cd ~/Downloads
sudo apt install ./CodexAppManager_arm64.deb
```

4. 输入这台电脑的登录密码。输入时屏幕上不会显示，输完直接回车。
5. 从应用程序列表打开 Codex App Manager。

## 第二步：在管理器里安装 Codex

1. 打开刚才装好的 Codex App Manager。
2. 首页写着「未检测到 Codex」时，点「安装 Codex」，等它装完。
3. Ubuntu 上会再要一次密码，这是在装官方的 Codex。
4. 首页已经能启动的话，说明 Codex 装过了，这一步跳过。

## 第三步：填自己的 API Key

1. 先完全退出 Codex。程序坞或任务栏里还有图标的话，退出它。开着的时候保存会被拦住。
2. 在管理器里打开「设置」，点「Codex 配置管理」。
3. 网关地址保持 `https://aiapi.yxrobot.com/v1`。
4. 在 API Key 里粘贴发给你自己的钥匙。不要用别人的。
5. 点「加载可用模型」。
6. 选一个带 `anthropic/` 的名字，例如 `anthropic/claude-sonnet-4.6`。不要选 `claude-opus-4-6`。
7. 思考深度保持「中」。
8. 点「保存」。看到「已保存」就可以。

## 第四步：开始用

1. 如果 Codex 还开着，完全退出。
2. 重新打开 Codex，新建一个对话。
3. 旧对话还会用旧模型。不要在旧对话里接着聊。

钥匙只在这台电脑上。换电脑要重新填一次。
